Diabetes Prediction using Machine Learning
Overview: This project predicts diabetes using Machine Learning techniques in Python. The dataset includes health-related information such as age, BMI, glucose levels, and HbA1c values.

Technologies Used:
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Project Steps
Data preprocessing
Handling missing values
Data visualization
Feature encoding
Model training using Random Forest Classifier
Model evaluation

Key Findings:
Higher BMI and glucose fasting levels were strongly associated with diabetes.
The Random Forest model achieved good prediction accuracy.

Conclusion: This project demonstrates how Machine Learning can help predict diabetes using medical data and health indicators.
